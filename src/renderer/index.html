        GitHub

        Sert à créer des dépôts quand gh n’est pas connecté. Le formulaire de GitHub s’ouvre pré-rempli : choisissez seulement « All repositories », puis collez le jeton ici. Il est vérifié auprès de GitHub, puis chiffré par le système. Les envois (push) gardent votre connexion Git habituelle.
