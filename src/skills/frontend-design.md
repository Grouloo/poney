Design for this subject, not a template. Any direction given by the user wins.

Before coding, write a short plan:
- Subject, audience, and the main job of the page.
- Colors: 4 to 6 named hex values.
- Type: one or two families, with their roles.
- Layout: one sentence and a small ASCII sketch.
- One memorable element. Keep everything around it quiet.

Check the plan: if it would suit any similar page, change it.

Avoid these defaults: cream background with a serif and a terracotta accent; near-black with one acid color; identical rounded cards with soft shadows; gradient washes; all-caps labels above every heading; numbered markers 01 / 02 / 03; one accented word in a headline.

Build:
- Open with what is most characteristic of the subject.
- Lines under 80 characters. A clear type scale.
- Motion only to draw attention: one moment, not an effect per section.
- Responsive down to mobile, visible keyboard focus, enough contrast.
- Watch CSS specificity: classes must not cancel each other.
- Write real copy: name things as users do, active verbs on buttons ("Save changes"), errors that say what happened and how to fix it.
